# Скриншоты

Здесь хранятся снимки экрана приложения для галереи в [корневом README](../../README.md).

## Список файлов

Галерея в [корневом README](../../README.md) ссылается на эти имена. Чтобы обновить снимок, замените PNG **с тем же именем**:

| Файл | Экран |
|---|---|
| `01-connect.png` | Подключение к серверу |
| `02-projects.png` | Список проектов |
| `03-sessions.png` | Список сессий |

Если добавите новые экраны, впишите их в таблицу галереи в `README.md` и заведите имена вида `NN-<экран>.png`.

## Как снять скриншот

Самый простой способ — с подключённого устройства или эмулятора через `adb`:

```bash
# снимок текущего экрана в текущую папку
adb exec-out screencap -p > 01-connect.png
```

Либо средствами устройства: на большинстве прошивок — сочетание кнопок питания и громкости, затем перенести файл на компьютер.

## Рекомендации

- Портретная ориентация, тёмная тема (основная в проекте).
- Разрешение — реального экрана; на GitHub ширина карточки небольшая, лишнее можно не масштабировать.
- Не показывайте на скриншотах реальные адреса серверов, токены и личные данные. Замазывайте или подключайтесь к локальному демо-серверу.
- Формат PNG; оптимизируйте размер (github сам покажет, но большие файлы замедляют загрузку).
