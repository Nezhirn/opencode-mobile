# Документация

Сборник документов по проекту OpenCode Mobile. Основное описание, возможности и инструкции по сборке — в [корневом README](../README.md).

## Содержание

| Документ | О чём |
|---|---|
| [REVIEW_FIXES.md](REVIEW_FIXES.md) | Разбор правок по итогам код-ревью: стабильность, отзывчивость, UI. Что было не так, к чему приводило, как исправлено |
| [screenshots/README.md](screenshots/README.md) | Как добавить и заменить скриншоты для галереи в README |
| [../CHANGELOG.md](../CHANGELOG.md) | История версий |
| [../CONTRIBUTING.md](../CONTRIBUTING.md) | Как участвовать в разработке и запускать проверки |

## Соглашения

- Документация ведётся на русском языке.
- Скриншоты хранятся в [`screenshots/`](screenshots/) с именами вида `NN-<экран>.png`.
- Технические детали изменений фиксируйте в `REVIEW_FIXES.md` или в соответствующем документе, а не в README.
